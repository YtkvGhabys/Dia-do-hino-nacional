# Dia-do-hino-nacional
Este é um site informativo e educativo desenvolvido para explorar a riqueza cultural e histórica do Hino Nacional Brasileiro. O projeto foca em uma interface limpa, priorizando a leitura e a acessibilidade das informações.

## Tecnologias Utilizadas
O site foi construído utilizando as tecnologias fundamentais da web:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização, layout responsivo e design visual.

## Estrutura do Site
O projeto é dividido em três seções principais para facilitar a navegação do usuário:

Página Inicial (Home): Apresentação do hino, com link da letra completa e algumas informações do projeto

História: Um mergulho na cronologia da composição, desde a melodia de Francisco Manuel da Silva até o poema de Joaquim Osório Duque-Estrada.

Curiosidades: Fatos interessantes e explicações sobre termos rebuscados para ajudar na compreensão da letra.

## Características do Projeto
Design Responsivo: Adaptado para leitura em computadores, tablets e smartphones.

Semântica: Código organizado para melhor indexação e acessibilidade.

Identidade Visual: Uso de cores que remetem aos símbolos nacionais de forma moderna e suave.
